## Featured project

### [FilamentOS](https://github.com/felipepcmourao/filament_os)

Stock, cost-per-print and sales tracker for 3D printing makers. I print and sell 3D pieces myself, so this app answers my own questions: how much filament is left, and what did each piece really cost.

- Domain with invariants enforced by factories, and value objects (`Money`, `Weight`) stored in integer minor units
- A `RegisterPrint` use case that validates and calculates everything before writing anything
- Feature-first Clean Architecture, Riverpod for state and dependency injection, GoRouter with auth guard, deep links and 404
- 7 architecture decision records, unit and widget tests, and CI running format, analyze and test on every pull request
